# CodeAlpha Stock Portfolio Tracker

A simple Python console program that calculates the value of stock quantities using a hardcoded price dictionary.

## Features
- Accepts stock symbols and quantities from the user.
- Calculates each holding and the total portfolio value.
- Saves the portfolio summary to `portfolio_summary.csv`.

## Requirements
- Python 3
- No external packages required.

## Run
```bash
python stock_portfolio_tracker.py
```

## Sample stock symbols
`AAPL`, `TSLA`, `GOOGL`, `MSFT`, `AMZN`

**Note:** Prices are fixed example values for programming practice. They are not live market prices or investment advice.

## Concepts
Dictionaries, loops, input/output, arithmetic, exception handling, and CSV file handling.
